# OwnLog 개념 가이드

OwnLog를 만들면서 쓴 기술과 작업 방식을 **개념부터** 설명하는 문서 모음이에요.
각 문서는 같은 순서로 되어 있어요.

1. **개념**: 이게 무엇이고 왜 필요한지 (쉬운 말과 비유로)
2. **이 프로젝트에서는**: 실제 파일 경로, 명령어, 저장소 이력에 남은 실제 사례
3. **자주 하는 실수와 FAQ**

코드나 설정을 바꾸기 전에 해당 문서를 먼저 읽으면, "왜 이렇게 되어 있는지"를 알고 고칠 수 있어요.
