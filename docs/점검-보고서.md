## 1. 고친 문제

### 보안
| 심각도 | 문제 | 어떻게 재현됐나 | 고친 방법 | 확인 |
|---|---|---|---|---|
| **높음** | **인코딩한 주소로 로그인 검사를 건너뜀** | `/%61pi/users/me`(=`/api/users/me`)를 토큰 없이 보내면 401이 아니라 컨트롤러까지 들어감(500). **운영 서버에서도 재현**. 로그인 없이 이미지 업로드도 가능했어요 | `SecurityConfig`가 디코딩하지 않은 주소(`getRequestURI()`)로 비교하던 것을, MVC와 같은 방식으로 비교하는 경로 패턴(`/api/**`)으로 바꿈 | `SecurityAuditTest`, `e2e/check-audit` |

### 정합성·버그
| 문제 | 고친 방법 |
|---|---|
| 글이 비공개가 된 뒤에는 내가 누른 좋아요·북마크를 취소할 수 없음 | 취소는 볼 수 있는지 대신 "발행된 글인지"만 확인 |
| 글·댓글·카테고리를 지우는 순간 들어온 좋아요·댓글·링크가 500 | 외래키 위반을 "대상이 방금 사라짐"으로 보고 404로 응답 (지우는 쪽이 막힌 경우는 그대로) |
| 글 요약에 `~~~` 코드 블록이 섞여 나옴 | 요약에서 `~~~` 코드 블록도 제거 |
| **(화면)** `/write/12`에서 헤더 "글쓰기"를 누르면 이전 글이 그대로 남고 "수정 완료"가 엉뚱한 요청을 보냄 | 글이 바뀌면 글쓰기 화면을 새로 그림 (처음 임시저장해서 주소만 바뀔 때는 이어서 씀) |
| **(화면)** 처음 임시저장 직후 계속 쓴 글자가 서버 값으로 덮어써짐 | 방금 저장한 글은 다시 불러오지 않음, 늦게 온 응답은 버림 |
| **(화면)** 이미지를 올리는 동안 쓴 글자가 사라짐, 같은 파일을 다시 고르면 반응 없음 | 올라간 뒤의 최신 본문에 붙이고, 파일 칸을 비움 |
| **(화면)** `[[` 자동완성에서 빨리 Enter를 누르면 이전 검색 결과가 들어감 | 검색어가 바뀌면 이전 결과를 비움 |
| **(화면)** 한글 입력 중 Enter로 태그·링크를 넣으면 글자가 두 번 들어감 | 한글 조합 중 Enter는 무시 |
| **(화면)** 화면 하나에서 오류가 나거나, 새로 배포된 뒤 예전 화면 파일을 못 불러오면 앱 전체가 하얗게 됨 | 오류 경계를 두고, 배포 때문이면 한 번 새로고침 |
| **(화면)** 새로고침할 때 네트워크 오류·배포 중(502)이면 로그아웃됨 | 401일 때만 토큰을 지움 |
| **(화면)** 좋아요를 누르고 바로 다른 글로 가면 다른 글에 좋아요 수가 섞일 수 있음 | 응답이 같은 글일 때만 반영 |
| **(화면)** 컴퓨터 시계가 빠르면 잠긴 캡슐을 계속 다시 불러옴 | 1.5초 → 3초 → 6초… 최대 30초로 점점 늦게 다시 물어봄 |
| **(화면)** 댓글·신고 버튼을 두 번 누르면 두 번 등록 | 보내는 중에는 막음 |
| **(화면)** 링크 미리보기 카드가 30초마다 닫히고, 좋아요를 누를 때도 닫힘 | 본문 컴포넌트를 매번 새로 만들지 않고, 시계는 타임캡슐 글에서만 돌림 |
| **(화면)** 타임랩스 재생 중 페이지 전체를 1초에 60번 다시 그림 (전체 우주는 별·선 수의 곱만큼 계산) | 타임랩스는 캔버스에 직접 알리고, 계산은 한 번만 |
| **(화면)** 같은 별을 다시 찾으면 이동하지 않음, 캔버스 밖으로 나가도 설명 상자가 남음, `?page=-3` 오류, 가입 화면 주소 예시가 다름 | 각각 수정 |

## 2. 고치지 않은 것 (판단과 이유)

| 항목 | 이유 | 언제 |
|---|---|---|
| **댓글 `parent_id`, 글 `category_id` 인덱스** | 댓글 삭제·글 삭제·탈퇴 때 표 전체를 훑어요. 새 마이그레이션(V6)이 필요해서 CLAUDE.md 규칙대로 **결정을 받고** 진행해요 (한 줄, 위험 낮음) | 승인되면 바로 |
| 검색(`ILIKE '%…%'`)·자동완성의 전체 훑기 | 지금 데이터(글 수십 개)에서는 문제없어요. `pg_trgm` 확장과 인덱스가 필요해요 | 2차 (README 계획 7번) |
| 목록마다 전체 개수(COUNT) 세기, 선택 필터의 인덱스 활용, 서비스 전체 우주 캐시 | 글이 수만 개가 되어야 체감돼요 | 2차 |
